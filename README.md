# tui-markdown

Markdown and diff rendering for [`tui-protocol`](https://github.com/egao1980/tui-protocol) programs on [cl-stack](https://github.com/egao1980/cl-stack): a streaming CommonMark-subset renderer and a diff renderer for [`diff-protocol`](https://github.com/egao1980/diff-protocol) values and unified text. Both emit lines of `tui-protocol/widgets` styled text runs. Harness plan track H, milestone H1c. Brief: [`cl-stack/docs/capabilities/tui-markdown.md`](https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/tui-markdown.md).

**Status: skeleton.** The contract (stubs and tests) is on a branch.
